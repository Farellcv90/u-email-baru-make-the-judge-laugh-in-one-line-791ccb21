# Make the Judge Laugh in One Line

> I hired a professional organizer to declutter my house. She took one look, handed me a match, and said, "Start over."

A one-line joke entry for the [make.fun](https://make.fun/bounty/u-email-baru-make-the-judge-laugh-in-one-line-791ccb21) competition **"Make the Judge Laugh in One Line"** — one funny line, 200 characters or fewer, judged head-to-head by an AI comedy-club booker.

## How to run

```sh
python3 main.py
```

This reads `entry.txt` and writes its exact content to `/output/entry.txt`.
